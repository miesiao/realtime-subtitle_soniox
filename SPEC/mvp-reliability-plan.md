# MVP 可靠性實作與營運說明

更新：2026-09-16。此版本已在本機完成，尚未部署，也未操作正式資料庫。

## 已完成

- 移除共用密碼、停用舊錄音頁；主持人以 Google 登入及場次所有權驗證。
- 音訊由伺服器轉送 Soniox，瀏覽器不取得供應商金鑰。只有供應商回報已處理音訊才扣點；麥克風拒絕、連線失敗與空結果不扣。持續收音中的靜音仍屬音訊用量。
- 純轉錄每分鐘 2 點、單一翻譯每分鐘 3 點，每開始一分鐘計一次。同場次同費率的進度、已付分鐘存入資料庫，暫停或重啟可沿用剩餘時間。餘額、用量帳本與已付分鐘於同一交易寫入，每分鐘有唯一扣款編號。
- 每個帳號同時一條音訊連線，每分鐘最多 10 次開啟；沒有音訊或供應商進度 15 秒中止，單次連線最多 2 小時。點數不足、控制連線中斷或上游失敗時停止轉送。
- 啟動時將 live 場次轉為 paused，重建同一場次、QR、單調遞增字幕序號與最近 50 段字幕。主持人恢復連線後按 Start 繼續；斷線期间未收取的音訊無法補回。
- IndexedDB 保存未確認文字，最多 500 段／5 分鐘；資料庫成功保存才 ACK，同一 clientMessageId 只插入一次。超限或保存失敗明確提示可能不完整；結束前等待補送，仍有待送內容時須確認。
- 原始逐字稿可獨立下載，只有場次擁有者有權限。整理以 Claude token 計數分段；非正常結束、空輸出與不完整分段不標記完成。
- 整理工作、分段結果、租約與來源版本持久化。手動重試沿用已完成分段；重啟可接續工作，晚到字幕會使舊工作失效，刪除後舊工作不能重新寫入。
- 刪除場次移除文字及整理資料，保留扣款原始場次編號。人工入帳和調帳皆有唯一編號、操作者、原因與交易紀錄。
- `/billing` 提供儲值訂單、末五碼回填、最近 100 筆訂單與 200 筆點數紀錄。
- `/privacy` 說明 Google、Soniox、Anthropic、Railway 的用途，AI 誤差、文字保存 30 天、刪除範圍與客服。SUPPORT_EMAIL 可設定，預設沿用既有聯絡信箱 subtiitw@gmail.com。
- 首頁移除紀要、三種譯文的宣稱，定位為即時字幕、單一翻譯及整理逐字稿。

## 資料遷移與保留

啟動會在單一交易套用 schema.sql；失敗即停止啟動，不以無法持久化的狀態接客。既有字幕序號依插入次序正規化。既有已結束逐字稿給予升級日起 30 天寬限；新場次自結束起計算。到期下載立即停止，內容於啟動及每小時清理，帳務不受影響。

開始版本以現有點數建立對帳期初餘額；舊帳可查，但不能事後證明升級前每一筆扣款都正確。以後禁止直接 UPDATE users.credits，使用下方工具，才能持續對帳。

## 人工入帳與對帳

工具使用環境中的 DATABASE_URL，僅由可信營運人員在正確環境執行。命令範例中的 ID、姓名與匯款參考編號需換成核對過的實際值。銀行參考編號應能唯一識別一筆匯款，不能只填末五碼。

```sh
node scripts/billing-admin.js confirm ORDER_ID --operator OPERATOR --reference BANK_TRANSACTION_ID
node scripts/billing-admin.js adjust USER_UUID 10 --id UNIQUE_ADJUSTMENT_ID --operator OPERATOR --reason "補回異常扣點"
node scripts/billing-admin.js reconcile
```

同一訂單或調帳編號重試不會再次加點。匯款參考編號不得套用兩筆訂單。reconcile 顯示期初、預期、實際餘額，差異時退出碼為 2。人工匯款公告為下一個工作日內確認，逾時請提供訂單編號聯络客服。

## 驗證與封測操作

`npm test` 使用隔離 PGlite PostgreSQL、真實本機 HTTP/WebSocket，測試扣點、回滾、去重、權限、分段、到期清理與帳本保留；不讀取 .env、不呼叫正式服務。

`npm run test:browser` 使用 Playwright Chromium、真實 Soniox 瀏覽器 SDK、假麥克風與假供應商，驗證未授權收音不扣點、暫停續播、IndexedDB 重載補送及到期提醒。需要本機可用的 Playwright，或設定 PLAYWRIGHT_MODULE_URL 指向既有安裝。

封測部署仍維持單一執行實例，活動期間避免部署，因即時觀眾路由與單一音訊鎖仍在程序記憶體。部署前先備份資料庫，於測試環境驗證遷移；部署後以真實 Google 登入、手機收音、Soniox/Claude、短場次與匯款核對流程做一次端到端演練。此版本未自動部署或執行任何正式入帳命令。

供應商音訊進度回報可能有少量在途成本；設定供應商用量通知與平台預算監看。整理完成檢查能辨識 API 截斷，不能保證模型完全不遺漏語意，重要內容仍須與原始稿核對。
